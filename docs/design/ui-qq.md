# QQ 音乐大屏 UI 规格

QQ 音乐页面以推荐、搜索、个人资产、智能电台和正在播放为核心。共享视觉、按键、Footer Legend 和宿主安全规则见 [UI 规则](ui-rules.md)。

## 全局结构

- 顶部内容首行：品牌色音乐图标与 QQ 音乐名称、顶层 Tabs、`L1/R1` 提示、当前播放状态徽章。
- 内容区：按当前 Tab 渲染全宽页面，不保留常驻左侧栏。
- 播放控制：无底部固定 MiniPlayer；`Start` 盲操播放 / 暂停，`Y` 打开队列浮层，完整控制在“正在播放”页；智能电台页只保留红心、播放 / 暂停、下一首。
- 登录：QQ 基本播放依赖扫码登录态。整页需登录的内容用 `LoginGate` 引导去 QAM 扫码，不渲染空个人资产。

## 顶层页面

| 页面 | 目的 | 关键交互 |
| :--- | :--- | :--- |
| 推荐 | 默认入口，展示智能电台入口、推荐歌单、新歌和榜单。 | `A` 播放或进入，`X` 更多操作，`L1/R1` 切页。 |
| 搜索 | 主动找歌入口。 | 搜索框 `A` 唤键盘；结果行 `A` 播放，`X` 菜单；`L2/R2` 切分类。 |
| 我的音乐 | 登录态资产入口。 | 二级 Tab：我喜欢、自建歌单、收藏歌单；内容区全宽列表 / 网格。 |
| 正在播放 | 封面、歌曲信息、同步歌词和完整播放控制。 | 十字键上下手动滚动歌词，4 秒静默后恢复跟随；左右微调进度。 |

智能电台不是顶层页签，从推荐页大卡进入独立路由。

## 推荐页

结构：

- 顶部两张大入口卡：猜你喜欢、雷达推荐。
- 推荐歌单网格。
- 新歌首发网格。
- 榜单区块（与 NCM 共用 `ToplistSection`）。

数据：

| 数据 | 用途 | provider 命令 / QQ API |
| :--- | :--- | :--- |
| 推荐歌单、新歌 | 首页网格。 | `recommend`：`get_recommend_songlist` + `get_recommend_newsong`，一个命令打包省 IPC。 |
| 猜你喜欢、雷达推荐 | 智能电台。 | `radio_fetch {kind: qq_guess / qq_radar}`。 |
| 榜单 | 榜单区块与详情。 | `toplists`、`toplist_songs`。 |
| 封面 | 前端直连 CDN，失败显示占位图。 | 按专辑 / 歌手 mid 拼 300×300 模板。 |

## 搜索页

结构：

- 顶部搜索框；输入即搜（600ms 防抖），无搜索按钮，清空回到热搜态。
- 分类 Tab：单曲、歌单、专辑、歌手。
- 空查询时显示热搜胶囊，`A` 直接搜索。

交互：

- 搜索框按 `A` 唤起软键盘。页面无底部固定栏，避免键盘压缩视口时遮挡内容。
- 单曲结果按 `A` 播放，并按当前搜索结果建立普通队列。
- 结果行按 `X` 打开上下文菜单。
- `L2/R2` 切分类；滚近底部自动翻页。

## 我的音乐

采用 Steam 官方库页面范式：全宽二级 Tab 行 + 全宽内容区。

- 未登录：`LoginGate` 引导，不渲染空红心、歌单、收藏列表。
- 已登录：账号信息放 QAM，不重复大头像 / 大横幅。
- 二级 Tab 带计数徽章：我喜欢、自建歌单、收藏歌单。
- “我喜欢”Tab 使用全宽高密度歌曲列表；歌单 Tab 使用全宽封面网格。
- `L2/R2` 切二级 Tab；十字键左右移动焦点，`A` 确认选中，十字键向下进入内容区。

## 智能电台

“猜你喜欢”和“雷达推荐”共用同一个沉浸播放器（`screens/Immersive.tsx`），但入口和模式标识必须明确。

- 不提供上一首。
- 当前批次播到阈值时由 bridge / provider 拉下一批。
- 页面只保留三类主要操作：红心、播放 / 暂停、下一首。
- `Y` 覆盖为红心，`X` 覆盖为下一首；Footer Legend 必须显示覆盖后的真实语义。
- 不显示全局队列浮层里的未来曲目，保持电台未知感。

## 正在播放

布局：

- 左侧三分之一：大封面、歌名、歌手。
- 右侧三分之二：同步歌词；当前行高亮，非当前行暗化。
- 控制组：进度、音量、上一首 / 下一首、播放模式。该页是完整控制入口。

交互：

- 十字键上下手动滚动歌词，4 秒静默后恢复跟随。
- 十字键左右在进度滑块上微调，停手后才提交 seek。
- `Start` 始终播放 / 暂停。

## 上下文菜单和队列

歌曲行通过 `X` 打开菜单：

1. 下一首播放。
2. 添加到队列末尾。
3. 收藏到歌单（二级菜单列自建歌单）。

菜单项目前固定显示；未登录或电台模式下失败/无效的入口尚未按状态禁用，失败走错误横幅。普通页面按 `Y` 打开队列浮层；智能电台页覆盖 `Y`，不展示未来曲目。

## 验收

- 未登录时，不渲染空资产或会失败的播放入口。
- 纯手柄能完成推荐播放、搜索播放、上下文菜单、队列浮层、正在播放页控制。
- 智能电台没有上一首入口。
- 软键盘弹出时没有底部播放条被顶起。
- 后端返回缺字段、空列表、不可播歌曲时 UI 保持可恢复错误态。
