# 网易云音乐大屏 UI 规格

网易云页面突出登录态个性化能力：发现、私人 FM、每日推荐、我的资产、逐字歌词和热评。共享视觉、按键、Footer Legend 和宿主安全规则见 [UI 规则](ui-rules.md)。

## 登录策略

**引导登录，不做全屏登录页。** 登录 UI 只维护 QAM 一份，符合“QAM 管全局控制，大屏管内容浏览”的分面：

- 匿名可用：搜索、免费歌播放、发现页推荐歌单。
- 整页需登录的内容（私人 FM、我的）用共享 `LoginGate` 空态：图标 + 提示 +
  「打开快捷菜单登录」按钮（`Navigation.OpenQuickAccessMenu()` 一键拉开 QAM），
  QAM 扫码成功经 login done 事件即时放行。
- 单点需登录的操作（每日推荐等）按错误码 `not_logged_in` 弹横幅引导。

## 全局结构

- 顶部内容首行：品牌色音乐图标与网易云音乐名称、顶层 Tabs、`L1/R1` 提示、当前播放状态徽章。
- 内容区：按当前 Tab 渲染全宽页面，不保留常驻左侧栏。
- 播放控制：无底部固定 MiniPlayer；`Start` 盲操播放 / 暂停，普通页面 `Y` 打开队列浮层，完整控制在“正在播放”页；私人 FM 只保留红心、播放 / 暂停、垃圾桶。

## 顶层页面

| 页面 | 目的 | 关键交互 |
| :--- | :--- | :--- |
| 发现 | 默认入口：每日推荐、推荐歌单、榜单。 | `A` 播放或进入，`X` 更多操作。 |
| 私人 FM | NCM 核心沉浸电台。 | `Y` 红心，`X` 垃圾桶并切下一首，`Start` 播放 / 暂停。 |
| 搜索 | 找歌和热搜入口。 | 搜索框 `A` 唤键盘，热搜词 `A` 直接搜索。 |
| 我的 | 账号资产。 | 二级 Tab：我喜欢、听歌排行、自建歌单、收藏歌单。 |
| 正在播放 | 逐字歌词、翻译、热评。 | `X` 在歌词 / 热评间切换。 |

## 发现页

结构：

- 每日推荐大入口卡。
- 推荐歌单网格。
- 榜单区块（与 QQ 共用 `ToplistSection`）。

交互：

- 每日推荐按 `A` 整单入队播放。
- 歌单卡片按 `A` 进入详情。
- 网格使用 `MAINTAIN_X`。

## 私人 FM

私人 FM 是专属播放器页面，不使用全局队列的完整未来列表。

- 没有上一首。
- 三个主操作：红心、播放 / 暂停、垃圾桶。
- `Y` 红心；`X` 垃圾桶并切下一首；`Start` 播放 / 暂停。
- 播到批次倒数第二首时补拉 FM 歌曲。
- Footer Legend 必须显示“红心 / 垃圾桶”的局部覆盖语义，而不是普通队列语义。

## 搜索页

结构：

- 搜索框；输入即搜（600ms 防抖），无搜索按钮，清空回到热搜态。
- 分类 Tab：单曲、歌单、专辑、歌手。
- 空查询时显示热搜胶囊。

交互：

- 搜索框按 `A` 唤起软键盘。页面无底部固定栏，避免键盘压缩视口时遮挡内容。
- 选中热搜词按 `A` 直接搜索。
- 结果列表按 `A` 播放或进入，按 `X` 打开菜单。
- `L2/R2` 切分类；滚近底部自动翻页。

## 我的

采用 Steam 官方库页面范式：全宽二级 Tab 行 + 全宽内容区。

- 不重复大头像 / 大横幅；账号信息与退出登录放 QAM。
- 二级 Tab 带计数徽章（计数为 0 时不显示）：我喜欢、听歌排行、自建歌单、收藏歌单；听歌排行当前计数恒为 0，不显示徽章。
- “我喜欢”“听歌排行”使用全宽高密度歌曲列表；歌单 Tab 使用全宽封面网格。
- `L2/R2` 切二级 Tab；十字键左右移动焦点，`A` 确认选中，十字键向下进入内容区。
- 听歌排行优先取最近一周；周榜为空时改取所有时间。

## 正在播放和热评

布局：

- 左侧三分之一：大封面、歌名、歌手。
- 右侧三分之二：逐字歌词、翻译或热评。
- 控制组提供进度、音量、上一首 / 下一首、播放模式。私人 FM 不显示上一首。

交互：

- 默认展示歌词；`X` 切换歌词 / 热评，图例同步。
- 十字键上下手动浏览歌词，4 秒静默后恢复跟随。
- 热评内容剥离 Steam 字体无法显示的 emoji 区段（U+1FA00+、变体选择符、ZWJ、私有区）。

## API 映射

| 能力 | UI 用途 | NCM API |
| :--- | :--- | :--- |
| 登录与账号 | QAM 登录页、账号态。 | `login_qr_*`、`login_status` + `vip_info` |
| 基础播放 | 搜索 / 队列播放。 | `song_url_v1` |
| 搜索 | 四类搜索结果。 | `cloudsearch` |
| 热搜 | 搜索页未输入状态。 | `search_hot_detail` |
| 每日推荐 | 发现页核心入口。 | `recommend_songs` |
| 推荐歌单 | 发现页网格。 | `personalized` |
| 榜单 | 榜单区块与详情。 | `toplist` + 歌单曲目 |
| 私人 FM | FM 页面歌曲流。 | `personal_fm` |
| FM 垃圾桶 | FM 页面跳过并反馈不喜欢。 | `fm_trash` |
| 红心 / 取消红心 | FM、当前曲、红心种子。 | `like`、`likelist` |
| 用户歌单 | 我的页面歌单分区。 | `user_playlist` |
| 听歌排行 | 我的页面 Tab。 | `user_record` |
| 逐字歌词和翻译 | 正在播放页。 | `lyric_new` |
| 歌曲评论 | 热评切换页。 | `comment_music` |

## 验收

- 未登录时需登录页面显示 LoginGate 引导，不渲染空数据。
- 纯手柄能完成发现播放、FM 红心 / 垃圾桶、搜索、队列浮层、歌词 / 热评切换。
- FM 页面无上一首入口。
- 软键盘弹出时没有底部播放条被顶起。
- 登录过期、二维码过期、接口空列表、不可播歌曲都进入可恢复错误态。
