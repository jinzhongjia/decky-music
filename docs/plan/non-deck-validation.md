# 非 Deck 设备验收

## 目标

把适配目标从“Steam Deck 上验证过”推进到“通用 x86-64 SteamOS 游戏模式验证过”。现有真机记录都来自 Steam Deck，不能推广到其他设备。当前因缺少硬件而阻塞。

## 范围

每台设备分别记录：

- SteamOS / Steam / Decky 版本。
- 实际用户名、UID 与插件安装路径（非 `deck` 用户、非 1000 UID、自定义目录不得改变播放与设置隔离语义）。
- 屏幕比例与缩放。
- 外接控制器的纯手柄操作。
- 默认音频输出与设备切换。
- 睡眠唤醒后的播放与 UI。
- 杀后端、断网、畸形数据下宿主存活。

Steam Deck 回归与该矩阵分开记录。Steam Deck 自身也尚未验证睡眠唤醒和蓝牙 / 外接音频切换，有条件时一并完成。

## 验收

- 上述每项都有对应设备的观测结果，写入 [设备兼容记录](../record/device-compat.md)。
- 真实 gamescope 会话里听到声音，Steam UI 全程不崩不冻。

完成后删除本文件，并更新 [架构](../design/architecture.md) 的兼容范围。
